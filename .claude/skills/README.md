# Skills

El menú está en [`INDICE.md`](INDICE.md). En Claude, escriba `/skills` para verlo.

- Cada skill vive en `NN-nombre/`; el número es su familia y su lugar en la cadena.
- Cada `SKILL.md` empieza con una ficha (`familia`, `version`, `entra`, `sale`, `siguiente`, `estado`).
- `INDICE.md` se genera con `python3 herramientas/indexar_skills.py`.
