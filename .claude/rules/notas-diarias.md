# Regla · Nota técnica del día

> Copia para Claude Code de la regla de AGENTS.md (*Nota del día*); si difieren, manda AGENTS.md.

- **Al abrir sesión:** lee la nota más reciente de `proyectos/<proyecto>/notas/` antes del `DASHBOARD.md`.
- **Al cerrar sesión:** crea `notas/AAAA-MM-DD.md` con estado, cambios, instrumentos, siguiente paso y alertas.
- La nota resume; **no aprueba nada**. Si choca con `DASHBOARD.md`, prevalece el dashboard.
- Avance siempre contado con `herramientas/contar_avance.py`.
